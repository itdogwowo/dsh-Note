## 兩種檔案，性質不同

**子系統文件**（`skills.md`、`plugins.md`……）是**活文件**：
理解變了就改，錯了就修，不保留舊版本。

**`pitfalls.md` 是 append-only**：
每一條是一個**發生過的歷史事件**，有日期。後來的理解可以補充，但不覆蓋原本記的症狀——
因為「當時以為是什麼」本身就是有價值的資訊（那正是下一個人會誤判的方向）。

## 寫作慣例

1. **只寫被絆到過的。** 從文件抄來的東西，直接連官方文件就好。
2. **每條要能驗證。** 寫「我推論是 X」沒有用；寫「打這個端點，200 就是活的」有用。
3. **一律用樣板。** `<你的帳號>`、`<專案>`、`<port>`——這個 repo 是公開的，見 [`privacy.md`](privacy.md)。
4. **不確定就標出來。** 分清楚「實測」「推論」「官方文件寫的」。
