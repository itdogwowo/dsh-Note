# CAD 圖 → 板框幾何

## 什麼時候用

- 機構給了 DXF／DWG，要在 PCB 上畫出對應的板框
- 現有板框要**內縮**（裝不進去）或**外擴**（要留間隙）
- 要從工程圖取出尺寸（弧半徑、帶寬、孔位）並**驗證**做出來的一致

---

## 步驟 1：解析 DXF

DXF 是**嚴格的「群碼／值」配對**文字檔（第 1 行是群碼、第 2 行是值、依此類推）。

```
0        ← 群碼
SECTION  ← 值
2
ENTITIES
```

⚠️ **先確認單位**：讀 `$INSUNITS`（`4` = mm）、`$MEASUREMENT`。
不要假設，也不要從數值大小猜。

**只取 `ENTITIES` 區段**（`TABLES`／`BLOCKS`／`OBJECTS` 裡也有同名圖元，混進去會多出一堆雜訊）。

| 圖元 | 需要的群碼 |
|---|---|
| `LINE` | `10,20`（起點）、`11,21`（終點） |
| `ARC` | `10,20`（圓心）、`40`（半徑）、`50`（起始角）、`51`（結束角） |
| `CIRCLE` | `10,20`、`40` |
| `LWPOLYLINE` | `90`（頂點數）、重複的 `10,20`、`70`（是否閉合） |

DXF 的文字是**成對**的，但值本身可能是數字——**不要用「這行是不是數字」來判斷是不是群碼**，
要從檔頭開始嚴格兩兩前進（並注意 BOM）。

---

## 步驟 2：縫合成閉合環

把圖元端點兩兩相接，串成環：

```
從任一未使用的邊開始 → 反覆找「下一條起點≈目前終點」的邊 → 直到回到起點
```

- 容差用 **0.05 mm** 級別（圖元端點可能有浮點誤差）
- 接不上就停，並**回報缺口距離**（不要靜默放棄）
- 一個環的**邊數**要合理（例如「2 弧 + 4 直線」）

⚠️ **陷阱：反轉一條邊時，圓弧的掃掠角必須一起反號。**
接續時若某條邊是「反向」接上的，它的起終點要互換——**圓弧的 sweep 也要取負**。
忘記這件事的後果：弧會**鼓向錯誤的一側**，形狀看起來「差不多」但其實是錯的。

---

## 步驟 3：內偏移（真多邊形偏移，不是縮放）

**「整體縮小 0.5mm」有兩種完全不同的做法，先問清楚是哪一種：**

| 說法 | 做法 | 結果 |
|---|---|---|
| 「每條邊往內 0.25mm」 | **多邊形偏移**（本節） | 壁厚少 0.5mm；**轉角處外接尺寸會縮超過 0.5mm** |
| 「外接尺寸縮 0.5mm」 | 依邊界框縮放或只移最大外形 | 壁厚變化不固定 |

### 演算法

1. **判方向**：用鞋帶公式算有號面積。`> 0` 為逆時針（內部在左）
2. **逐邊偏移**（`g` = 方向係數，逆時針為 `+1`；`d` = 偏移量）
   - **直線**：沿左法線平移 `g·d`
     （左法線 = 把方向向量逆時針轉 90°：`n = (-uy, ux)`）
   - **圓弧**（掃掠角 `θ`）：**圓心不變、半徑改變**
     `r' = r − g·d·sign(θ)`
3. **重算接點**：偏移後相鄰邊不再共點，要重新求交
   - 線∩線：解兩直線交點
   - 線∩圓：解直線與圓的交點，**取靠近原接點的那一個**
4. **弧的角度範圍要重算**：新端點的極角，掃掠量取「與原值同向且最接近」的那個
   （`delta = 新掃掠 − 原掃掠`，把 `delta` 正規化到 ±180° 內再加回去）

### 驗證（必做）

| 檢查 | 期望 |
|---|---|
| 每條邊的內移量 | **恰好** `d`（實測可到 1e-13 級） |
| 帶寬（同心弧的半徑差） | 原值 − `2d` |
| 閉合 | 起終點距離 ≈ 0 |
| 包含性 | 偏移後的所有取樣點都落在原輪廓內，面積變小 |

> ⚠️ **反直覺但正確**：每邊內縮 0.25mm 時，**外接矩形寬度會縮 0.53～0.66mm**，
> 不是剛好 0.5。因為轉角是**斜接**——相鄰兩邊的偏移線交點會跑得更外面。
> **徑向「壁厚」才是剛好 −0.5**。
> 要對外接尺寸做精確控制時，必須改用另一種算法，不能靠偏移。

---

## 步驟 4：寫進 PCB

板框要寫成 `POLY` + `polyType:"BOARD_OUTLINE"`（**不是** layer 11 上的線），
座標單位是 **mil**。細節見 `easyeda-eprj3-format`。

換算：`mil = mm × 39.3700787`。

---

## 三個會算錯幾何的陷阱

### 1. 邊界框只取端點 → 漏算弧頂

一條圓弧的**最高點不在端點上**，而在頂點（極角 90° 處）。
只取端點算 bbox 會**少算約 7mm**（半徑 264、跨 27° 時），
導致排版重疊或板材浪費。

→ **取樣整條弧**再算 bbox，不要只取兩端。

### 2. 旋轉不是繞著弧心 → 同心關係跑掉

多個同心弧的形狀要整體旋轉時，**必須繞共同圓心旋轉**，
否則弧心會位移，偏移與半徑計算全部失效。

→ 若所有弧共用同一圓心，旋轉就以它為中心；順便讓「點在某角度」的取樣變得極簡單。

### 3. 忘了弧的掃掠角在縫合時會被反轉

見步驟 2 的警告。**症狀是形狀「看起來對」但鏡像了**，肉眼很難發現。

→ 驗證方式：反算半徑要等於設計值，且**鼓向要與原圖一致**（取弧中點的極角檢查）。

## 跟人對齊用詞

「公差」「間隙」「內縮」「外擴」在機構與 PCB 之間常指不同東西。動手前先確認：

1. 是**每條邊**移一個量，還是**外接尺寸**縮一個量？
2. 是**單邊**的量還是**雙邊合計**？
3. 材質與製程（FR4 銑切 vs 壓克力雷切）的公差量級不同

> 問一句話，省一次打樣。
